## [v0.7.10] - 2026-08-02

### 关联版本
* Android：`v0.6.3`
* Cli：`v0.2.9`

### 技术改进/重构 (Changed/Refactor)
* 重构 `audio_core` 的 module-first 组织方式，将 `mini`、`flash`、`pro` 和 `ultra` 的规则、编码、解码与 tone rendering 拆分为独立模块，并保留 `phy_clean` 作为兼容 facade，保持既有编解码行为不变。
* 重构 `audio_core` transport 与 Flash voicing 内部实现：按 encode work-plan、follow timeline、voicing support 等稳定职责划分 owner，并将同一流程的阶段推进、生命周期、进度与终态结果保留在内聚实现中，避免为降低行数制造碎片。
* 重构 `bag_api` 的 decode operation 与 encode 测试组织，将 operation entrypoints 保持为完整流程 owner，并将异步 encode/decode 测试按行为域拆成专用文件，保持现有 C ABI 与 operation contract 不变。
* 重构 `audio_io` WAV metadata 校验与解析边界，将 metadata rules 提升为独立 module/source owner，由 WAV backend 通过明确命名空间调用，保持现有 WAV 与 metadata 解析语义不变。
* Android 不支持 C++ modules 的 native package adapter 与宿主 module source 复用同一个 canonical implementation owner；职责扫描会展开本地 `.inc` 并计入包含方，避免兼容层复制实现或绕过扫描阈值。
