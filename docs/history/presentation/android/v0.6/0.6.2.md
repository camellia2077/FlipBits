## [v0.6.2] - 2026-08-02

### 关联版本
* Core：`v0.7.9`
* Web：`2026-08-02`

### 新增功能 (Added)
* 增加 Ultra 的 MFSK16 速度选择器，支持 `15.625 Bd` 和 `31.25 Bd` 两个按键选项，并复用 Mini 的速度选择交互。
* 增加 Ultra MFSK16 速度对应的多语言界面文本；`MFSK16` 与 `Bd` 保持固定词汇，速率数值保持原样。

### 技术改进/重构 (Changed/Refactor)
* 调整 Ultra 的 Android native 参数，使界面可视化与编码使用 MFSK16 的 16 tones、15.625 Hz/31.25 Hz 间隔及对应符号率，并按真实符号边界处理采样数。
* 调整 Mini、Flash、Pro、Ultra 的解码请求，在缺少音频 metadata 时向 Core 透传 `frame_samples=0`，由 Core 根据 `mode` 和 `sample_rate_hz` 解析时序。
* 调整 Flash 解码入口，移除 Android 侧按 voicing 风格逐项回退的猜测逻辑，改由 Core 统一完成候选解析和校验。
* 调整 Ultra 进度跟随和可视化字段，将帧尾标记为 `Tail`，并按单符号粒度展示 MFSK16 频率变化。

### 修复 (Fixed)
* 修复 Android JNI 将自动时序 sentinel 归一化为默认 frame samples 的问题，使无 metadata 的整段 clean PCM 能保持自动解析契约。
* 修复 Ultra 旧频率表和固定符号时长与 MFSK16 标准参数不一致的问题，使 `15.625 Bd` 与 `31.25 Bd` 的生成、解析和可视化使用一致边界。
