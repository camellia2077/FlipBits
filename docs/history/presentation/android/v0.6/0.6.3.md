## [v0.6.3] - 2026-08-02

### 技术改进/重构 (Changed/Refactor)
* 重构 Android Compose 配置与播放展示职责，将主题对话框状态/选择器、Flash visualizer render model、播放展示策略/可视化、歌词区和 follow annotation layout 拆分为独立文件，保持现有界面行为不变。
* 重构 JNI bridge 的 marshalling 边界，将 `ArrayList`/通用列表操作与 follow raw segment、display unit DTO 构造从聚合 helper 中拆出，保持现有 Kotlin domain 对象和 native ABI 映射不变。
* 重构 Android native package 的 Flash signal、各 mode PHY 与 WAV I/O source owner；Android compatibility adapter 按规则、编码、解码和 rendering 边界编译，并与宿主 module source 复用 canonical implementation，避免维护两份实现。
* 将 Android `versionName` 更新为 `0.6.3`。
