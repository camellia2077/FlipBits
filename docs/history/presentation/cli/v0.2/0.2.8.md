## [v0.2.8] - 2026-08-02

### 改动意图
* 收口 Rust CLI 的 FFI、命令用例和 Presentation 边界，为后续 Android/Web 消费层重构保留清晰的 CLI contract。

### 技术改进/重构 (Changed/Refactor)
* 重构 `bag_api` 与 `audio_io_api` FFI adapter，将 ABI 定义、配置转换、生命周期 guard、操作流程、metadata/WAV 转换和错误处理从单文件拆分到职责明确的模块目录，保持 C ABI 和 native 所有权语义不变。
* 重构 CLI 命令编排，将 `encode`、`decode` 和 CLI metadata policy 拆分到 `commands/`，让命令用例只通过 adapter 使用共享库，不再承载裸指针、C ABI 常量或释放逻辑。
* 重构 Presentation 层，将参数解析、文件 IO、错误类型、终端进度、版本输出和 stdout/stderr 输出集中到 `presentation/`，并把 `main.rs` 收敛为解析、执行和输出分发入口。
* 冻结 CLI 行为基线，明确 `version`、`licenses`、`encode`、`decode` 的输出通道、错误退出码、WAV metadata v7 和 encode/decode round-trip 契约，补齐重构后的维护入口文档。

### 修复 (Fixed)
* 修复 CLI 维护文档与实际 Rust 模块布局不一致的问题，`apps/audio_cli/AGENTS.md` 现在指向新的 `commands/`、`presentation/`、`bag_api/` 和 `audio_io_api/` 目录。
* 修复内部模块重排后容易误暴露 Presentation 文件 IO 的边界，文件读写保持 crate 内部使用，用户结果继续写入 stdout，进度和错误继续走 stderr。
