## [v0.2.9] - 2026-08-02

### 技术改进/重构 (Changed/Refactor)
* 重构 Rust CLI 的 `bag_api` FFI adapter，将 ABI 定义、配置转换、decode、operation、错误处理和生命周期 guard 按职责组织到 `rust/src/bag_api/`；operation guard 自身负责 poll/result 生命周期，模块间使用显式依赖，保持既有 C ABI 与所有权语义不变。
* 重构 `audio_io_api` FFI adapter，将 ABI、WAV/状态处理、metadata 转换、资源 guard 和共享 raw string 转换组织到 `rust/src/audio_io_api/`，保持既有 WAV/metadata 行为不变。
* 重构 CLI 命令与 Presentation 边界，将 `encode`、`decode`、metadata policy 放入 `commands/`，将参数解析、文件 IO、错误、输出、进度和版本输出放入 `presentation/`，并收敛 `main.rs` 为执行与输出分发入口。
* 更新 `apps/audio_cli/AGENTS.md` 的维护入口和模块路径说明，使文档与新的 Rust crate 目录结构保持一致。
