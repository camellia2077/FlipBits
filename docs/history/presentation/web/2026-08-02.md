## [v0.7.9] - 2026-08-02

### 关联版本
* Core：`v0.7.9`
* Android：`v0.6.2`

### 新增功能 (Added)
* 增加 Web Ultra 的 MFSK16 速度选择区域，提供 `15.625 Bd` 直接选择按钮，并在生成请求中携带所选速度。

### 技术改进/重构 (Changed/Refactor)
* 调整 Ultra 的模式名称和说明，将旧的 `16-FSK` 表述统一为 `MFSK16`，并明确默认速率为 `15.625 Bd`。
* 调整 Web 表单的 Ultra 时序计算，按 `15.625 Bd` 将采样率换算为符号采样数，并与 Mini 的速度字段保持独立。
* 调整多语言资源，补齐 Ultra 速度标签和 MFSK16 说明；`MFSK16`、`Bd` 与速率数值作为固定技术词汇保留。
* 调整 Ultra 速度选项的页面布局、可见性和无障碍标签，使其仅在选择 Ultra 模式时显示。
